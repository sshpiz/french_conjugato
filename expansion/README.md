# Verb Expansion Layer (Normalized Artifacts)

This folder contains shared tooling + documentation for expanding verb inventory and improving glosses **without** rewriting repo-native runtime files (`js/verbs.full.js`) as the primary work product.

Canonical execution brief:

- `/Users/simeon/Desktop/proj1/VERB_EXPANSION_AND_GLOSS_UPGRADE_PROMPT.md`
- `/Users/simeon/Desktop/proj1/VERB_EXPANSION_CLARIFICATIONS.md` (authoritative)

## Principles

- Runtime/output stays repo-native.
- Expansion artifacts can use a shared normalized shape.
- Merges should be previewable, reviewable, and resumable.

## Normalized Artifacts

Each app repo may contain:

- `expansion/verb_expansion_candidates.json`
  - normalized list of new verb lemmas to add later (core vs stretch, optional register/style/category metadata)
- `expansion/expansion_review.md`
  - human review notes for the expansion-layer work

Gloss expansion is currently handled by:

- `verb_glosses.generated.json` + `verb_glosses_review.md` per repo (generated by `generate_multilang_verb_glosses.py`)

## Merge Rule (Safety)

Merge helpers should default to writing **sidecar outputs** (under `expansion/`) and only overwrite repo-native seed/runtime data when explicitly requested.
