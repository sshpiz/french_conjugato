## Classification Legend

- `deterministic-safe`: local deterministic conjugation/generation is reliable.
- `deterministic-plus-review`: mostly deterministic, but depends on external sources and/or known quality risks.
- `model-assisted`: OpenAI/model help is required for key gaps (conjugations and/or core metadata), or is the only practical expansion path right now.
