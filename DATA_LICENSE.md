# Data License Notes

This pipeline is designed to ingest Kaikki/Wiktextract data derived from Wiktionary.

Practical assumption for this project: normalized graph data, indexes, and learner-facing related-word exports produced from Wiktionary/Kaikki sources should be treated as CC BY-SA-compatible derived datasets. Published or shared datasets should include attribution to Wiktionary contributors and Kaikki/Wiktextract as applicable, and should use ShareAlike-compatible terms.

The pipeline code itself can remain under this repository's own code license.

This file is a practical project note, not legal advice.
